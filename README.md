# Теория кодирования — Лабораторный практикум (УрФУ)

Современное Android-приложение на **Jetpack Compose** и **Clean Architecture**, предназначенное для расчета и визуализации ключевых алгоритмов теории информации и кодирования.

---

## 📌 Архитектура проекта

Приложение построена по принципам **Clean Architecture** (Separation of Concerns) с явным разделением на слои:

## 🛠 Ключевые возможности и модули

### 1. Внутреннее представление чисел
* Перевод операндов в прямой, обратный и дополнительный коды.
* Определение адаптивной разрядной сетки (2, 4, 8, 16, 32 бит).
* Двоичное сложение операндов с пошаговой хронологией решений.
* Автоматическая проверка правильности знака и вычисления десятичного эквивалента.
* Горизонтальный скролл разрядной сетки для 16/32-битных результатов и плавная фокусировка на итоговой карточке.

### 2. Лабораторная работа №1: Эффективное кодирование
* **Источники сообщений:** готовые варианты из таблицы 1.1, произвольный ввод вероятностей и частотный анализ произвольного текста (>100 символов).
* **Алгоритмы кодирования:**
  * Метод Шеннона — Фано.
  * Оптимальный метод Хаффмана.
* **Рассчитываемые метрики:**
  * Энтропия источника $H = -\sum P_i \log_2 P_i$
  * Максимальная энтропия $H_{\max} = \log_2 N$
  * Средняя длина кодового слова $L_{ср} = \sum P_i \cdot l_i$
  * Коэффициент статистического сжатия $K_{сс} = H_{\max} / L_{ср}$
  * Коэффициент относительной эффективности $K_{оэ} = H / L_{ср}$

### 3. UI/UX Особенности
* **Material Design 3 (Material You):** полная адаптивность под светлую и тёмную темы, мягкие скругления (16–28 dp), тональные контейнеры.
* **Интерактивный алфавит (`EnsembleDialog`):** плавающее диалоговое окно для комфортного просмотра всех символов $a_i$, их вероятностей и процентов без конфликта жестов прокрутки.
* **Интерактивная справка по формулам (`MetricsExplanationCard`):** раскрывающийся блок с формулами, физическим смыслом каждого коэффициента и алгоритмическими различиями методик.
